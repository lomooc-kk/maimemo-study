# 记忆卡正文语法摘要

墨墨记忆卡（Markji）的卡片 `content` 不是富文本，而是一套方括号标记。写进 `POST /markji/.../cards` 的正文如果不符合规则，卡片里会显示成纯文本。

下面按「通用规则 → 行内语法 → 块级语法 → 常见错误」整理。完整规则以墨墨官方文档为准（<https://open.maimemo.com/>）。

## 通用规则

- 用 `#` 分隔标签名、参数和内容。**没有参数也要保留两个 `#`**，例如 `[E##x+y]`。
- 标签名和参数区分大小写，必须写成 `T`、`P`、`F`、`Choice`、`Pic`、`Audio`、`Card`、`E`。
- 多个参数用英文逗号分隔，标签名、参数、分隔符之间不加空格。
- 每个标记都必须有未转义的 `]` 收尾。
- 普通正文里要显示方括号本身时，写成 `\[` 和 `\]`。
- 除特别说明允许的位置外，不要嵌套标记。拿不准就用普通文字，别指望写错的语法被自动修好。

## 行内语法

可以和普通文字写在同一段里。

| 用途 | 写法 | 参数 |
|---|---|---|
| 文字样式 | `[T#参数#文字]` | `B` 加粗、`I` 斜体、`U` 下划线、`!rrggbb` 文字色、`!!rrggbb` 底色、`up` 上标、`down` 下标、`link/"网址"` 超链接 |
| 挖空 | `[F#编号#要隐藏的内容]` | 编号是从 1 开始的正整数；同号同组，一起显示或隐藏 |
| 音频 | `[Audio#参数#显示文字]` | `ID/音频ID` 指定音频，`M` 手动播放，`A` 自动播放，`D` 跟随用户设置 |
| 卡片引用 | `[Card#ID/卡片ID#显示文字]` | 多张卡片用连字符连接，如 `ID/a1-b2` |

样式可以组合，用逗号隔开，例如 `[T#B,U,!e53935#红色加粗下划线]`。颜色写 6 位小写十六进制、不带 `#`；`up` 和 `down` 不要同时用；样式内容里不要再嵌别的标记。

例：

```text
光合作用主要发生在[F#1#叶绿体]中。
[T#B#线粒体]是[T#I#细胞器]之一。
```

## 块级语法

必须**顶格另起一行**，前面不能有别的文字。

| 用途 | 写法 | 说明 |
|---|---|---|
| 段落样式 | `[P#参数#内容]` | `H1` 标题（只有 H1）、`L` 无序列表、`I<n>` 缩进、`left` / `center` / `right` 对齐 |
| 选择题 | `[Choice#参数#` + 每行一个选项 + 单独一行 `]` | `multi` 多选，`fixed` 固定顺序（不写则随机） |
| 图片 | `[Pic#ID/图片ID#]` | 带遮罩写 `[Pic#ID/图片ID,MID/遮罩ID#]`；内容区必须为空，所以结尾是 `#]` |
| 独立公式 | `[E##公式]` | 公式单独一行，`]` 后不要接普通文字 |
| 答案分隔线 | `---` | 三个半角连字符单独一行，前后不加空格 |

选择题的选项必须从新行开始，正确项写 `* `、错误项写 `- `（符号后有一个空格）。多个正确答案要加 `multi`。选项里只能放普通文字和 `[T#...#...]` 样式。

相邻且**没有换行**的多张图片会合成一个画廊；想分成两块就换行写。

例：

```text
[P#H1#细胞结构]

以下哪些是哺乳动物？
[Choice#fixed,multi#
* 鲸
- 鲨鱼
* 蝙蝠
- 企鹅
]

勾股定理：
[E##a^2+b^2=c^2]
```

## 嵌套与位置限制

| 容器 | 能放什么 |
|---|---|
| 普通段落、`P` 段落 | `T`、`F`、`Audio`、`Card` |
| `Choice` 选项 | 只有 `T` |
| `T` / `F` / `Audio` / `Card` 的内容或显示文字 | 不再嵌套 |
| `Pic` | 内容必须为空 |
| `E` | 只写公式 |

块级语法（`P`、`Choice`、`Pic`、独立 `E`、`---`）不要放进段落或其他标记内部。

## 常见错误

| 错误 | 正确 |
|---|---|
| `[F#1挖空]` 少一个 `#` | `[F#1#挖空]` |
| 块级标记前有文字（`题目：[Choice##`） | 把 `[Choice` 另起一行顶格 |
| 多选题漏了 `multi` | `[Choice#multi#` |
| 选项写成 `*正确` | `* 正确`（符号后有空格） |
| 正文里的 `[0,1]` 直接写 | 写成 `\[0,1\]` |
| 用不存在的图片、音频、卡片 ID | 只能用真实 ID：图片音频先上传拿 ID，卡片 ID 从接口读 |

## 写完自检

1. 标签和参数大小写对吗？
2. 每个标记都有两个结构 `#` 和正确的结尾 `]` 吗？
3. 块级标记都是顶格另起一行吗？
4. 选择题选项都是准确的 `* ` / `- ` 前缀吗？多选加了 `multi` 吗？
5. 挖空编号都是正整数，分组符合预期吗？
6. 普通文字里的括号都转义成 `\[` `\]` 了吗？
7. 标题只用 `H1`，颜色都是 6 位小写十六进制吗？
8. 图片、遮罩、音频、关联卡片 ID 都是真实存在的吗？
